# 执行进度卡

本技能用 Markdown 清单与 HTML 进度标记更新插件任务卡。

## 推进格式

1. **开场建卡**：在首条进度汇报后，直接输出 3–6 项三态清单（第 1 项用 `[/]` 标记进行中，其余用 `[ ]`）：
   - `- [/] 第一阶段任务`
   - `- [ ] 第二阶段任务`
   - `- [ ] 第三阶段任务`
2. **阶段推进**：切换到第 `N` 阶段时附 `<!-- todo:N/M -->`，没有新发现时可以只发标记。确实无法继续时可附 `<!-- todo:N/M blocked -->`。
3. **完成收尾**：汇总结果和验证证据，列出尚待验证的工作。全部阶段确认完成时附 `<!-- todo:done -->`。

## 演示模式

当用户发送「演示执行进度卡」或调用 `/progress-card` 要求演示时，按以下三阶段执行：

1. 首句汇报并输出起始清单：
   - `- [/] 查看当前目录`
   - `- [ ] 执行等待验证`
   - `- [ ] 核对结果`
   然后查看当前目录内容。
2. 汇报发现并附上 `<!-- todo:2/3 -->`，执行无副作用的 `sleep 8`（`run_command` 等待阈值设为至少 `10000` 毫秒，保证同一次调用内完成）。
3. 汇报命令退出情况并附上 `<!-- todo:3/3 -->`，核对最终结果；全部核对无误后，在最终回复末尾附上 `<!-- todo:done -->` 完成演示。
